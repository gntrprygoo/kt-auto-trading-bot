# Contributing

Describe the changed behavior and affected component. Use synthetic examples without private configuration or account records.

Run the regression suite with Python 3.12:

```text
python -m unittest discover -s tests -v
```

Execution, sizing, protection, and AI gate changes should cover relevant failure behavior. Update operational runbooks when interfaces change. Keep research outcomes separate from claims about live performance.

No open-source license is currently granted; discuss substantial contributions and reuse with the maintainer.
