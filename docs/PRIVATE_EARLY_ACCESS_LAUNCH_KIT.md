# KT Auto Trading Bot Private Early Access Kit

Update: 2026-07-10

Dokumen ini dipakai untuk share private ke teman, kerabat, status WhatsApp, status Instagram, dan grup kecil. Tujuannya bukan langsung jual massal, tetapi membuka early access terbatas dengan filter user yang paham risiko.

## Tujuan Fase Ini

- Mengumpulkan 5-10 calon user awal yang serius.
- Menguji alur onboarding dari Telegram.
- Mengukur pertanyaan paling sering dari user.
- Menjaga ekspektasi: bot membantu proses, bukan menjamin profit.
- Mendapat feedback sebelum launch lebih luas.

## Positioning Singkat

```text
KT Auto Trading Bot adalah bot trading Binance Futures berbasis rule, risk control, dan report Telegram.

Bot berjalan 24 jam di VPS, membantu scan market, eksekusi strategi, monitoring posisi, SL/TP, SL+, dan report performa.

Bot tidak menjamin profit. Futures tetap berisiko.
```

## Syarat User Early Access

Calon user yang cocok:

- Sudah punya akun Binance.
- Sudah atau siap mengaktifkan Binance Futures.
- Mengerti bahwa futures bisa rugi.
- Mau mulai dari ukuran kecil.
- Mau membuat API key dengan Withdrawal OFF.
- Mau mengikuti onboarding lewat Telegram.

Calon user yang belum cocok:

- Mencari profit pasti.
- Ingin all-in.
- Tidak mau membaca disclaimer.
- Belum paham dasar futures sama sekali.
- Meminta bot menghilangkan semua risiko.

## Checklist Sebelum Menerima User

- User menjawab paham risiko.
- User tidak meminta jaminan profit.
- User bersedia mulai kecil.
- User bersedia API Withdrawal OFF.
- User bisa mengikuti command Telegram.
- Admin punya waktu mendampingi onboarding.

## Kuota Awal

Rekomendasi:

- Batch 1: 3 user paling dekat dan paling mudah diarahkan.
- Batch 2: tambah 5-7 user setelah alur setup lancar.
- Jangan langsung buka terlalu banyak, karena bottleneck awal biasanya support dan edukasi.

## Catatan Tone

Gunakan bahasa tenang dan jujur. Jangan pakai kata-kata seperti profit pasti, anti loss, cuan harian, atau modal kecil jadi besar. Lebih baik membangun trust dari transparansi dan proses.
