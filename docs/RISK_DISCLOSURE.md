# Risk Disclosure

KT Auto Trading Bot adalah alat bantu otomasi trading berbasis rule. Bot ini bukan jaminan profit, bukan nasihat keuangan, dan bukan pengganti tanggung jawab pengguna.

## Risiko Trading Futures

Trading futures memiliki risiko tinggi. Pengguna bisa mengalami kerugian modal, termasuk kerugian yang lebih cepat dari ekspektasi karena:

- Leverage.
- Volatilitas market.
- Slippage.
- Gap price.
- Likuidasi.
- Gangguan koneksi.
- Error exchange/API.
- Salah konfigurasi API atau notional.

## Risiko Bot

Bot dapat mengalami masalah teknis, antara lain:

- API Binance gagal atau lambat.
- Telegram notification terlambat.
- Journal lokal tidak sinkron.
- Order conditional tidak terbaca sempurna.
- VPS/laptop mati.
- Internet putus.
- Perubahan rule exchange.

Karena itu, pengguna wajib tetap memonitor posisi dan akun Binance.

## Bukan Janji Profit

Hindari ekspektasi seperti:

- Profit pasti.
- Anti loss.
- Auto cuan.
- Akurasi tetap.
- Modal kecil pasti menjadi besar.

Positioning yang benar:

Bot membantu eksekusi strategi swing secara disiplin, memakai fixed notional dan risk control, serta memberikan report posisi/performa lewat Telegram.

## Praktik Aman

- Mulai dari simulate mode.
- Gunakan notional kecil saat real mode.
- Jangan aktifkan withdrawal permission pada API key.
- Gunakan IP whitelist jika memungkinkan.
- Jangan membagikan API key.
- Cek posisi live secara berkala.
- Jangan mengabaikan alert posisi tanpa SL.
- Jangan cancel order lama tanpa cek posisi terlebih dahulu.

## Tanggung Jawab

Semua keputusan trading, konfigurasi, penggunaan API key, dan risiko kerugian menjadi tanggung jawab pengguna.
