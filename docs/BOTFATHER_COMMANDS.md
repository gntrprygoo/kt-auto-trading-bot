# BotFather Commands

Gunakan daftar ini di BotFather melalui `/setcommands`.

```text
start - mulai dan lihat menu utama
register - daftar sebagai calon user
myaccount - lihat status akun
license - lihat status license
onboarding - panduan setup client
api_guide - cara membuat API Binance
setup_api - setup Binance API aman
api_status - cek status API
delete_api - hapus API dari config bot
cancel_setup - batalkan setup API
status - status bot dan mode entry
health - cek koneksi dan kesiapan bot
positions - lihat posisi aktif
orders - lihat open orders Binance
report - report performa hari ini
weekly - report performa minggu ini
monthly - report performa bulan ini
alltime - report performa keseluruhan
shadow - pantau shadow signal strategi
d1shadow - pantau Strategy D1 forward shadow
pause - hentikan entry baru
resume - aktifkan entry baru
risk - lihat dan atur risk management
help - tampilkan bantuan
admin_users - daftar user untuk admin
admin_pending - daftar user pending
admin_approve - approve user
admin_revoke - revoke user
admin_extend - perpanjang license user
```

Catatan:

- Command tetap hanya berjalan jika script Python sedang aktif.
- Menu Web App belum diperlukan untuk fase private beta.
