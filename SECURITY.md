# Security

Never commit API secrets, Telegram tokens, config.json, account registries, journals, worker credentials, or private trading records. Use config.example.json as the template and separate evaluation credentials and state paths.

Review deployment scripts before use. Keep AI live eligibility disabled during evaluation.

Do not include sensitive records in public issues. Contact the maintainer through contact details on their GitHub profile. Revoke exposed credentials at the provider and replace them before continuing.
